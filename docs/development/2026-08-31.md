## REQ-002 独立声音分析仓库资产迁移与可运行基线补全

### 实施基线

- 目标仓库只有文档、无密配置、两个 Python 环境和空模型目录，没有服务源码、启动入口、组件测试或统一编排。
- 目标仓库根 `AGENTS.md` 引用的 `docs/governance/document-architecture.md` 不存在。
- 相邻 Smart Badge 当前工作区存在用户的其他未提交改动，本次不得触碰；可迁移资产来自只读 `refer/badge/smart_badge` 和历史提交 `60d283c55b634ff87870e2ae540b2ba4af44437d`。
- ECAPA 和 segmentation-3.0 的本地文件与历史 Git LFS SHA256 一致；旧 OSD 专用模型不完整，但目标配置默认关闭 OSD。

### 实际实现

- 以 Smart Badge 根 README 的组织形式为参考，重写 Voice Analysis 根 README；删除所有 Smart Badge 公网地址、Swarm、数据库、Redis、业务角色、管理端和 H5 说明，改为本仓库真实地址、环境、模型、启动和测试入口。
- 迁入并重命名 8077 为 `voice_embedding_service`，保留 SpeechBrain ECAPA 批量调度、窗口协议和逐项失败语义。
- 迁入 8078 `window_refine_service`，保留 miniaudio 解码、pyannote segmentation-3.0 和窗口细化算法。
- 两个业务接口增加 `X-Voice-Analysis-Key` 鉴权；两个服务增加 `/health/ready`，只在真实模型加载后返回 ready。
- 8078 在调用模型前将 `audio_path` 解析并限制在 `VOICEANALYSIS_AUDIO_ROOT` 内，同时拒绝不存在的文件。
- ECAPA 和 segmentation-3.0 模型写入被 Git 忽略的 `runtime/models`；新增 `config/model-manifest.json`，记录来源提交、路径、大小和 SHA256。
- 新增模型安装与校验、前台启动、联合后台启动、PID 精确停止、组件测试和真实模型探针脚本。
- 统一模型下载和长时压测辅助脚本的模型目录、鉴权头和目标仓库命名；pyannote 下载入口默认只获取当前主链使用的 segmentation-3.0。
- 两套直接依赖增加 pytest，重新生成完整依赖锁并安装到现有隔离环境。
- 改写两个组件 README 和 Dockerfile；Dockerfile 使用仓库根作为 build context，并要求运行时挂载模型。
- 将根 `AGENTS.md` 的项目名称和测试命令改为 Voice Analysis 当前真实入口。
- 在根目录新增 `PROJECT_STATUS.md`，记录当前结构、资产、已具备能力，以及统一编排 API、聚类、句段归属、Web 前端、评测和部署的后续需求。
- 补齐目标仓库文档职责规范，并更新架构、HTTP 契约、配置、本地运行手册和文档入口。

### 验证

- `scripts/install-models-from-smart-badge.ps1`：对已存在且正确的模型重复执行无新增修改，校验通过。
- `scripts/verify-workspace.ps1`：配置、环境、服务源码、FFmpeg 和模型完整性通过。
- `.venv-embedding` 组件测试：16 passed、1 skipped；跳过项需要私有 ECAPA parity PCM 语料。
- `.venv-refine` 组件测试：4 passed。
- `scripts/start-local-services.ps1`：两个模型进程启动并在超时内进入 ready。
- 8077 真实健康：`speechbrain_ecapa`、`ecapa_voxceleb_v1`、192 维、CPU、模型 ready。
- 8078 真实健康：`pyannote_segmentation`、segmentation-3.0、CPU、模型 ready，重叠来源为 `segmentation_powerset`。
- `scripts/smoke-services.ps1`：真实 ECAPA 返回 192 维 L2 归一化向量；真实 pyannote `/segment` 成功。

- 没有迁入私有真实录音或 parity 语料；合成波形探针只能证明模型和协议可运行，不能证明业务准确率。
- 统一上传、异步任务、候选窗口编排、质量评分、NME/加权 KMeans、句段归属、完整转写和 Web 前端仍未实现，详见根 `PROJECT_STATUS.md`。
- 当前没有生产环境、公网地址、部署记录或远程运行事实。
- 依赖测试存在 Starlette TestClient 弃用警告，窗口音频代码存在 Python 3.13 `audioop` 弃用警告；当前固定 Python 3.11，不影响本次运行结果，后续升级前需要处理。
