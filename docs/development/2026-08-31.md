## REQ-007 M1 基础评测门槛配置化

### 实际实现

- 新增 `config/evaluation.yaml`，建立 `m1_baseline_v1` 评测 Profile。
- 配置使用 100 ms 评分帧、250 ms collar、计入重叠、按录音宏平均并允许 speaker 最优置换映射。
- 基础门槛确定为 DER ≤ 0.30、JER ≤ 0.40、说话人数完全正确率 ≥ 0.80、说话人数 MAE ≤ 0.30、已分配句段准确率 ≥ 0.85、非 `unknown` 覆盖率 ≥ 0.80、`unknown` 比例 ≤ 0.20。
- 最低数据集规模确定为 20 份录音、合计 60 分钟，并要求单人、双人、多人、重叠、噪声/远场场景各至少 3 份。
- 配置登记 PriMock57、AISHELL-4 和 AliMeeting 为优先公开来源，MagicData-RAMC 仅限符合其非商业许可的用途。
- 更新项目状态、配置说明和文档入口，明确公开数据评测可以独立启动，不再等待人工补充基础指标。

### 验证与未验证项
